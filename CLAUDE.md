# ai-office.ge — правила работы с сайтом

Международная витрина продукта AI Office (пре-лонч, набор пилотных компаний). Статика на GitHub Pages, DNS Cloudflare, `git push` в `main` = деплой (~1 мин). Домен привязан файлом `CNAME` — **не трогать**.

## Структура
- `index.html` — вся главная; CSS страницы inline, общие токены/nav/footer/кнопки — в `assets/base.css`.
- `privacy.html`, `terms.html`, `thanks.html`, `404.html` — на той же навигации и `base.css`.
- `assets/fonts/*-latin.woff2` — self-hosted Bricolage Grotesque и Hanken Grotesk (Google Fonts не подключать: privacy-страница обещает отсутствие третьих сторон).
- `assets/logo-mark.svg`, `assets/stamp.svg`, `assets/og-image.png`, `assets/apple-touch-icon.png` — айдентика одной семьи.
- `design/` — эскизы и черновики, в `.gitignore`, не деплоятся. Любые новые черновики класть туда.
- `.impeccable/` — снапшоты дизайн-критики, в `.gitignore`.

## Дизайн-система
- Палитра монохромная: бумага `#f6f4ee`, чернила `#22302a`, зелёный `#2e5c48` / `#1f4234`. Второй цвет один — янтарный `#7a5310` на `#faebd0`, и только со смыслом «нужен человек» (`span.hold`). Новые цвета не вводить.
- Шрифты: Bricolage Grotesque (заголовки, 600–800), Hanken Grotesk (текст, 400–700).
- Логотип: инлайн SVG `class="mark"` (галочка из рамки, `currentColor`) + `<span class="wm"><b>AI</b> Office</span>`; правки — во всех пяти страницах синхронно.
- Запреты (из дизайн-аудита): боковые цветные полоски-накладки, градиентный текст, стекло, одинаковые сетки карточек «иконка+заголовок+текст», кикеры капсом над каждой секцией, «verified/official/limited»-бейджи, тире-emdash в копии.
- Мобильный: без горизонтального переполнения на 375 px; меню-бургер ≤820 px; печать и фолио-строка скрыты на узких экранах.

## Контент
- Всё честно: нет выдуманных клиентов, метрик, логотипов, отзывов. Продукт на пре-лонче.
- Основатель без имени (решение владельца). Позиционирование международное: Грузия только в юр-футере, языках и «First up: TBC, Bank of Georgia, RS.ge». В сценариях чата суммы в лари — сохранять.
- Цены early access $39/99/249 — черновые, менять только по решению владельца.

## Форма заявки
- Formspree, endpoint в `action` формы (`/f/meaqzonz`), письма идут на hello@ai-office.ge. JS: inline-валидация, success-блок, при сбое сети — mailto-фолбэк, при требовании капчи — нативный POST с редиректом на `/thanks.html`.
- Антиспам: скрытое поле `_gotcha`, проверка скорости заполнения, фильтр Formspree. Тестировать только правдоподобным содержанием: «тестовые» тексты Formspree отбрасывает в Spam без письма.

## Чат в хиро
Сценарии — массив `S` в скрипте `index.html` (4 сценария рабочего дня, непрерывная лента с разделителями времени, кнопка паузы). Добавляя сценарий, держать 4 реплики и одну кнопку-чип с авто-нажатием.

## Проверка перед пушем
1. `node ~/.claude/skills/impeccable/scripts/detect.mjs --json index.html` — должно быть `[]`.
2. Локально: `python3 -m http.server 8099` → 375 px без переполнения, консоль без ошибок, все `assets/` отдаются, `CNAME` = `ai-office.ge`.
3. `git status` — в коммит не должны попасть черновики; `git pull --rebase` перед пушем (GitHub иногда сам коммитит `CNAME`).
